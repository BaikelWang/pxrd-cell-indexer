# 20260727–20260802

1. **RealPXRD 迁移路线完成验证，主线正式锁定 PXRD-indexer**：先做 RealPXRD 微调三臂，10k 下最好的 Arm A 将候选库召回从 4% 提到 11%，但未过 15% 门槛；随后补做 100k 消融，RealPXRD 各变体都停在 **40–44% library@100**，低于 PXRD-indexer 的 **51%**。原因也已确认：RealPXRD 的 XRD encoder 只有约 3.7 万参数、峰位按 1° 量化，CSPNet 在纯峰输入下基本是死重。结论不是继续抠迁移结构，而是保留 RealPXRD 结果作对照，主线回到从零训练的 PXRD-indexer，并修复选模集只含立方/四方的盲区，改为按晶系分层、严口径选模。

2. **McMaille 从“照搬”推进到可控的端到端引擎，并完成多引擎对标**：忠实复刻原生单候选链路后，依次补上度规张量 LSQ 精修、修复反射数护栏未定义行为、扩大推理 K，MP100 Top-1 从 **24% 提升到 46%**。其中护栏修复是关键一步，单独把 Top-1 从 26% 拉到 **44%**；CELREF 恒为 0 的两个 bug（NaN 污染、倒易胞未转回直接胞）也已定位并修复。最终 v4 端到端在统一 primitive L4-strict 上，MP100 Top-1 **49%**，高于 TREOR90 35%、JADE9 30%、原生 McMaille 28%；CNRS Top-1 **39%**，高于 DICVOL91 17.1%、TREOR90 11.4%、原生 McMaille 8.1%。

3. **Reranker 把大候选池的召回优势兑现到 Top-1，最新 MP100 达到 60%**：K 从 100 增到 1000 后，MP100 库召回由 59% 提到 69%，但 McM20 排序几乎不涨；CNRS 更出现库变高、Top-1 反降。为此用独立合成扰动数据冻结出简单线性重排器，核心信号不是重复算峰匹配，而是 **McM20 + 神经网络距离 + 体积先验**。冻结评测中，CNRS K=1000 从 31.7% 提到 **41.5%**，MP100 K=1000 从 50% 提到 **57%**，四个候选池均无下降。最新 V5 在 MP100 上进一步把 K=1000 的库召回提高到 74–75%，端到端 Top-1 达到 **59–60%**；但 V5 在 CNRS 没有同步提升，当前 CNRS 最佳仍是 **V4 + K=100 + reranker：43.1%**。

**核心结论：**
- 模型侧：RealPXRD 迁移上限已量清，主线锁定 PXRD-indexer；选模协议已修正。
- 引擎侧：McMaille 关键 bug 与精修链路已补齐，我们在 MP100、CNRS 的统一严格榜上均排第一。
- 排序侧：K=1000 的大池不再只是“召回高但排不动”；Reranker 已把 MP100 Top-1 推到 **60%**，开始接近产品目标。

**关键数字：**
- MP100 primitive L4-strict：Ours V5 **60%**；TREOR90 35%；JADE9 30%；原生 McMaille 28%。
- CNRS primitive L4-strict：Ours 最佳 **43.1%**；DICVOL91 17.1%；TREOR90 11.4%；原生 McMaille 8.1%。
- Reranker 冻结增益：MP100 K1000 **50%→57%**；CNRS K1000 **31.7%→41.5%**。
- RealPXRD 迁移：40–44% library@100；PXRD-indexer：51%。
