## 1. 问题重述

McMaille 现在做的事：**在 4 维连续参数空间 `(a,b,c,β)` 里做 Monte Carlo 盲采样**，采样完才用 `CALCUL1` 检验能不能解释观测峰。

代数种子法反过来：**假设峰对应的 Miller 指数 `(h,k,l)`，直接从峰位置解方程得到 `(a,b,c,β)`**，把 McMaille 现有的 `CALCUL1`/`CELREF2` 只用来做「验证 + 精修」，不再用来做「搜索」。

---

## 2. 数学基础（已用 McMaille 自身代码核对，见 `DCELL`/`AL` 矩阵）

单斜（α=γ=90°）的倒易度量关系：

```6470:6477:third_party/McMaille/run_lab/McMaille_omp_fixed.for
      DO 34 I=1,3
      AL(I,I)=RCELLN(I)*RCELLN(I)
      CALL PERM(I,J,K)
      IF(J-K)35,36,36
35    AL(J,K)=2.0*RCELLN(J)*RCELLN(K)*RCELLN(I+3)
      GOTO 34
36    AL(K,J)=2.0*RCELLN(J)*RCELLN(K)*RCELLN(I+3) 
34    CONTINUE
```

对应：

\[
Q_{hkl} \;=\; \frac{1}{d_{hkl}^2} \;=\; A\,h^2 + B\,k^2 + C\,l^2 + F\,hl
\]

其中 `A=a*²`、`B=b*²`、`C=c*²`、`F=2a*c*\cosβ*`（另两个交叉项因 α=γ=90° 恒为 0）。

**关键性质**：给定 `(h,k,l)`，`Q_{hkl}` 是 `(A,B,C,F)` 的**线性函数**。

反推真实空间参数：

\[
\cos\beta=\frac{-F}{2\sqrt{AC}},\quad
a=\frac{1}{\sqrt{A}\sin\beta},\quad
c=\frac{1}{\sqrt{C}\sin\beta},\quad
b=\frac{1}{\sqrt{B}}
\]

合法性约束：`A>0, B>0, C>0`，且 `|F|\le 2\sqrt{AC}`（否则 `cosβ` 越界，无实数解）。

峰的观测量：`Q_i = (2\sinθ_i/λ)^2`（`θ_i` 为观测峰的布拉格角）。

## 3. 核心难点：不知道每个峰的 `(h,k,l)`——这是组合搜索问题

若对每个峰都暴力枚举小指数再联立解 4 元方程：

\[
N_{\text{brute}} \approx (\text{每峰候选指数数})^4
\]

取 `|h|,|k|,|l|\le5`（centrosymmetric 折半后约 600 种/峰），4 峰联立：

\[
600^4\approx1.3\times10^{11}
\]

**比现在 MC 的 10⁶–10⁷ 还夸张，不能用。**

---

## 4. 降复杂度：晶带分解（de Wolff / Ito 经典思路）

### 4.1 技巧 A —— 先找晶带（zone），把 4 元问题拆成 3 元

`k=0` 的反射（`(h0l)` 型，`[010]` 晶带）只涉及 `A,C,F` 三个未知数：

\[
Q = Ah^2+Cl^2+Fhl
\]

**做法**：在最低角（最大 d、信噪比最好）的若干峰中，尝试找出「同属一个晶带」的 3-4 个峰——判据是它们的 `Q` 值能被同一个 3 参数二次型联立解出，且解出的 `A,C,F` 满足合法性约束（`A,C>0`，`|F|\le2\sqrt{AC}`），同时反推出的 `a,c,β` 落在合理晶体学范围内。

命中一个合法晶带 = 锁定 `a,c,β`。

### 4.2 技巧 B —— 晶带定了之后，`b` 轴变成一元搜索

`A,C,F` 已知后，剩下 `k≠0` 的峰只需要试小整数 `k=1,2,3,…`（范围很小，通常 ≤5-6）：

\[
B=\frac{Q_{\text{obs}}-(Ah^2+Cl^2+Fhl)}{k^2}
\]

多个峰应给出**同一个 `B`**（一致性校验），不一致立刻剪掉——这一步的代价近似 `O(峰数 \times k范围)`，很便宜。

### 4.3 复杂度对比

\[
N_{\text{zone}}\;\sim\;\underbrace{\binom{\text{低角峰数}}{3\text{或}4}\times(\text{小指数范围})^{3}}_{\text{找晶带}}
\;+\;
\underbrace{N_p\times(\text{小}k\text{范围})}_{\text{定}b\text{轴}}
\]

数量级估计：**10³–10⁴**，比当前单斜 MC 的 10⁶–10⁷（外层试探）低 2-3 个数量级。

## 5. 建议架构：种子生成器 + 复用现有验证/精修

```text
观测峰表 (Q_i, i=1..NDAT)
  │
  ├─【新增】晶带分析 + 线性解方程 → 候选种子 (a,b,c,β) 列表（数量级 10²-10³）
  │
  └─【复用，不改】CALCUL1 算 Rp → 好的种子送 CELREF2 精修 → 候选表
```

好处：
- 工程风险集中在「种子生成器对不对」，不需要重写候选管理、FoM、精修等已验证过的老代码；
- 种子生成器可以先在 **Python 里做原型**，完全不碰 Fortran，验证过关再决定是否移植/挂接。

## 6. 已知风险（不回避）

| 风险 | 说明 |
|---|---|
| **零点误差敏感** | 晶带识别依赖少数峰的精确 `Q` 值联立求解；零点偏移会让 `Q` 系统性偏移，进而让解出的 `a,c,β` 整体漂移。MC 因为是整体拟合，天然对系统误差更容错。需要专门处理（比如把零点也当未知数联立求解，或迭代修正）。 |
| **杂质峰/漏峰敏感** | 若参与晶带识别的低角峰里混了杂质峰或误判峰，晶带就找错，后续全错。MC 对少数坏峰更鲁棒（整体拟合，坏一个峰不至于整体崩）。 |
| **简并/伪晶带** | 小样本（峰少）时，「凑巧」满足晶带线性关系的假阳性概率不低，需要额外的合法性/自洽性过滤，这正是经典程序里最琉璐的部分。 |
| **工程量** | 是「新写模块」，量级远超 Tier 1/2 的参数微调。 |
| **已有轮子** | DICVOL06、TREOR90、ITO 已经把这些坑踩过一遍。**先看能否复用/移植现成实现，而不是从零推导 de Wolff 算法**，可能性价比更高——本构想暂不判断这一点，留给下一步调研。 |

## 7. 建议的验证路径（分阶段，不承诺一定采用）

1. **Python 原型**（不碰 Fortran）：只实现「晶带识别 + 线性解方程 + 合法性过滤」，输出候选种子列表。
2. **种子质量评估**：在 MP100 的单斜子集（n=15，已有真值和峰表，见 `mp100_compare/`）上，检验：
   - 种子列表里有没有「离真解足够近」的候选（近到丢给 `CELREF` 能收敛）；
   - 种子数量级是否真的比 MC 试探次数低 2-3 个量级；
   - 对零点偏移（人工加扰动）、丢峰（人工删峰）的鲁棒性。
3. **Gate**：种子质量不过关（比如召回率明显低于 MC），暂停，不投入 Fortran 侧改造；过关再讨论混合架构落地方式。
4. **调研现成实现**（可与步骤 1 并行）：看 DICVOL06/TREOR90 是否有可直接调用/移植的开源实现，评估「重新实现 vs 复用」的性价比。
