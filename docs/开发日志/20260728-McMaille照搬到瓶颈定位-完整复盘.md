## 起因：一次方法论纠偏

此前一直在自研的「非破坏多阶段」接法上打转——一颗种子在库里留多行以最大化 library，
并针对 McMaille 的各个环节做局部改造。但**从没把原生 McMaille 拿到候选之后的链路
原样跑过一遍**。属于没照搬就先改，是在瞎创新。

本次先做忠实复刻，跑通、看结果、再定位问题、再改。事后看这条路径是对的：
最终找到的根因（打分函数里一处提前返回）靠推测永远想不到。

## 主线：四步，Top-1 从 24% 到 46%

| 阶段 | 关键动作 | library@100 | Top-1@100 |
|---|---|---:|---:|
| 0. 非破坏多阶段（原基线） | — | 68% | 35% |
| 1. 忠实照搬原生链路 | policy=1 | 34% | 24% |
| 2. + LSQ 精修 | `--refine lsq` | 35% | 26% |
| 3. + 反射数护栏修复 | `MCM_NHKL_CAP=400` | 57% | **44%** |
| 4. + 推理 K=1000 | — | **64%** | **46%** |

第 3 步之后，忠实照搬的链路**首次超过我们自研的多阶段**（44% vs 36%）。

## 三次判断修正

复盘时值得记录的是，中间有三个判断被后续证据推翻：

**（1）「门控是唯一瓶颈」——只对一半。**
第 1 步定位到门控杀掉 52% 的正确答案，做了精修后过门率从 32/67 涨到 51/67，
但最终库只有 35%。损失还在门后。

**（2）「SUPCEL / 去重 / RMAX2 在杀答案」——全错。**
插桩后 `lost_after_gate = 1`、`killed_rmax2_only = 0`。门控之后几乎什么都没丢，
RMAX2 从不单独触发。最看好的两条线索都不成立。

**（3）「缺口是误杀，可以补回来」——相反。**
最后 10 个被 Rp 杀掉的样本，几何误差中位 3.51%，0% 在 0.5% 以内。
L4-strict 的 `ltol=0.05` 让 3–4.7% 的胞也算命中，Rp 给出的才是诚实判决。
其中 4 个在原始池里根本没有命中，是 McMaille 局部 MC 漂出来的。

## 根因：一处未定义行为

`CALCUL1` 里：

```fortran
      NHKL=JH
      IF(NHKL.GT.NDAT10)RETURN        ! NDAT10 = NDAT*10
```

反 overfitting 护栏，逻辑合理，**但 RETURN 时没给 DIFF 赋值**，
调用方拿着上一次求值的残留 Rp 去过门。

我们天天踩它：`.dat` 只喂 20 个峰，上限 200 条反射；但 DMIN 由第 20 个峰决定、
覆盖到 2θ≈67°。**护栏是比值检验，我们截断峰表却保留完整 2θ 范围，把比值搞崩了。**

插桩过程中两次无意改了行为，回滚验证后成了干净对照——同一份代码，
这条未定义路径怎么解释，library 就在 **28% / 35% / 49% / 57%** 之间摆动。
只有「放开上限、老实打分」那一种是真的算了分。

## 技术产出：度规张量约束最小二乘

Nelder-Mead 直接优化 2θ 残差失败（1% 扰动下误差从 2.44% 涨到 3.54%），
因为 hkl 指派每步翻转、残差布满局部极小。

改为**固定 hkl**：`Q = h²A+k²B+l²C+klD+hlE+hkF` 对度规张量分量线性，
且七个晶系约束在同一组基里也线性 → 有闭式解的约束线性 LSQ。
加容差退火（1.5°→0.15°，因为 1% 误差在 60° 处推开峰约 0.66°）和多梯子重启
（收敛与否取决于首轮指派，结果双峰）。

1% 扰动下达标率 4% → **58%**，成功时误差直接到机器精度。

## 终点：瓶颈已转移到生成侧

K=1000 池的 73% recall 拆开：

| 最好几何误差 | 样本数 |
|---|---:|
| <0.2%（干净过门） | 38 |
| 0.2–1% | 23 |
| 1–5%（擦边） | 12 |
| 完全没命中 | 27 |

真正堪用（<1%）只有 **61%**，而全流程 library 已做到 **64%**——
**下游把种子池榨干了，甚至靠局部 MC 多捞了一点。**

失败分析给出两条主轴：**晶系自由度**（cubic 100% → triclinic 0%，完美单调）
和**晶胞尺寸**（good 中位 169 Å³ vs miss 586 Å³）。

决定性证据是**体积先验偏小**：miss 组候选体积中位只有真值的 **0.51 倍**，
±10% 内候选占 **3.5%**，6/27 连 90% 体积都够不到。
**模型压根不往大胞采**，这解释了 coverage 曲线为何在 K=100 后躺平。
