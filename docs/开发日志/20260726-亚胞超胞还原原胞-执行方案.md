# 亚胞/超胞 → 正确原胞：执行方案

> 执行者：Composer。本文档自带全部背景、已验证结论、可直接调用的资产、
> 每一步的验收 Gate 和已知坑。**请严格按 Phase 顺序执行，不通过 Gate 就停下来报告，不要自行加戏。**

---

## 0. 一句话目标

我们的候选池在**宽松口径**下几乎总能命中真胞的某个亚胞/超胞（库 loose = 100%），
但在**严格口径**（`|det|≈1` 且能 indexed 峰）下几乎全灭。
本任务只做一件事：**把已经拿到的亚胞/超胞，还原成能拟合衍射峰的正确原胞。**

不要去改神经网络种子，不要去改 McMaille 搜索本身，不要去调 FoM 权重玄学。

## 1. 现状（全部为实测数字，勿凭空推翻）

### 1.1 三引擎对比（真值 = **原胞**，`results/l4_prim_vs_conv.json`）

| | Top-1 loose | Top-1 strict | Top-20 loose | Top-20 strict | 库 loose | 库 strict |
|---|---:|---:|---:|---:|---:|---:|
| JADE9 | 36% | 30% | — | — | — | — |
| McMaille 原生 | 36% | 28% | 39% | 28% | — | — |
| **我们（phase4 池）** | 22% | **1%** | 70% | **5%** | **100%** | **10%** |

### 1.2 池内候选相对真胞的最小 `|det|`（`results/pool_min_det_to_truth.json`）

中位数 **4**；`|det|=1` 仅 **9%**；`|det|≤4` 覆盖 63%；`|det|≤8` 覆盖 **93%**。

→ 真胞基本都是池内某个胞的**低指数超胞**，这就是本任务可行的根据。

### 1.3 已做过的扩胞实验

`results/subcell_to_primitive.json`（HNF 扩胞，index≤8，目标=原胞）：

| 匹配容差 | 几何严格可恢复 | 恢复后还能 indexed 峰 (cov≥0.8) |
|---|---:|---:|
| ltol=0.05, atol=3° | **100%** | **18%** |
| ltol=0.02, atol=1° | 68% | 17% |
| ltol=0.01, atol=0.5° | 37% | 15% |

`results/expand_then_refine.json`（扩完再做**非线性**精修）：
cov≥0.8 从 18% → 28%，严格且 cov≥0.8 = **26%**。

**结论：几何上几乎总能扩出来，但扩出来的胞对不上峰。**

### 1.4 本轮新验证（关键）

旧实验的顺序是「**扩胞 → 精修**」，错在基胞本身带 2–5% 度量误差，
乘上 index 后误差放大，精修（只能救 ≲1% 误差）拉不回来。

改成「**先精修基胞 → 再扩胞 → 再精修**」，20 样本探针：

| 顺序 | 严格且 cov≥0.8 |
|---|---:|
| 扩胞 → 精修（旧，100 样本） | 26% |
| **精修 → 扩胞 → 精修（新，20 样本）** | **50%** (10/20) |

**这就是本方案的核心假设，已验证成立。**
（注：探针用了真值体积窗剪枝，仅用于加速探针，正式流程必须换成峰导出的体积先验。）

## 2. 现成资产（直接用，不要重写）

### `scripts/cell_refine.py`（本轮新增，已验证）

| 函数 | 作用 | 已验证行为 |
|---|---|---|
| `refine_cell(params, obs_2θ, symmetry=...)` | 度量张量**线性**最小二乘精修 | 真胞扰动 0.5% → 精确还原（残差 3e-9）；扰动 1% → cov 0.88；扰动 ≥2% 失效 |
| `fom_stats(params, obs_2θ)` | 返回 `coverage / m_n / n_poss / n_indexed / mean_dq` | de Wolff `M_N = Q_N / (2·mean_dq·N_poss)` |
| `symmetrize_and_refine(params, obs_2θ)` | spglib 吸附对称 + 约束精修 | 把差 0.7° 的畸变胞还原成真解，M_N 从 86 → 3.1e6 |
| `candidate_symmetries(params)` | 提名近似满足的晶系 | — |
| `SYMMETRY_BASES` | 7 晶系在度量张量 6 维向量中的线性子空间 | 约束拟合仍是普通最小二乘 |

原理备注：`Q = 1/d² = h²G₁₁ + k²G₂₂ + l²G₃₃ + hk·2G₁₂ + hl·2G₁₃ + kl·2G₂₃`
对倒易度量张量六分量是**线性**的，所以每轮精修是一次 lstsq，远比在
`(a,b,c,α,β,γ)` 上做非线性优化稳健。

## 3. 统一口径（**任何实验都用这一套，不许换**）

```python
真值      = truth_cells(cif)["prim"]        # 原胞，不是 conventional
几何匹配   = find_mapping(ltol=0.05, atol=3.0)
严格       = 几何匹配 且 |det(scale) − 1| < 0.25
峰覆盖     = 前 20 条观测峰中与理论反射差 ≤ 0.05° 的比例
最终命中   = 严格 且 峰覆盖 ≥ 0.8          # 「powder_strict」
分母       = 100
波长       = 1.54184 Å
```

**只报 `最终命中`。** 单独的几何 `find_mapping` 有大量假阳性，不得作为结论。

## 4. 执行计划

### Phase 1 — 全盲还原率（最重要，先做这个）

**目标**：在不使用任何真值信息的前提下，测「精修 → 扩胞 → 精修」的还原率上界。

**流程**（每个样本）：

1. 读 `PHASE4/{sid}/{sid_}.allcells`，用 `cell_key` 去重得到 pool
2. 对每个 pool 胞跑 `refine_cell` → 得到精修后的基胞与 `fom_stats`
3. 按 `(-n_indexed, -m_n)` 排序，取前 `max_bases` 个作为基
4. **峰导出体积先验（不得用真值）**：
   - `d_max` = 最大 d 值 = 最小 2θ 对应的 d
   - `V_center = (1.6 · d_max)³`，体积窗 `[V_center / k, V_center · k]`
   - `k` 由 Composer 标定（起点 k=3），只允许用峰数据
5. 对每个基胞，枚举 index `n = 1..max_index`，仅保留 `V_base · n` 落在体积窗内的 `n`
6. 对每个 HNF 矩阵 `H`：`L = H @ base.matrix` → 取参数
   - 先用 `fom_stats` 快筛，`n_indexed < 3` 直接丢
   - 再 `refine_cell`；若 `coverage < 0.8` 再试 `symmetrize_and_refine`
7. 命中 `最终命中` 即 early-exit 记为 recovered

**产出**：`scripts/eval_subcell_to_prim_v2.py` + `results/subcell_to_prim_v2.json`

参数：`--max-bases 100 --max-index 8 --workers 16`，全 100 样本。

**必须记录**：还原率、index 直方图、每样本耗时中位数、体积窗命中率
（真胞体积是否落在峰导出体积窗内 —— 这一项**允许**用真值，因为只是诊断先验质量）。

#### Gate 1
- **≥ 60%** → 通过，进 Phase 2
- 50–60% → 先做体积窗 `k` 与 `max_bases` 的小扫描（各 3 档），再判
- **< 50%** → **停下报告**。重点排查体积先验是否把真胞排除了

---

### Phase 2 — 排序（把还原出来的胞顶到 Top-1）

**前提**：Phase 1 通过。

Phase 1 是 early-exit 的「可还原率」，是上界。本阶段不做 early-exit，
把所有候选保留下来排序。

**排序依据**：`(coverage ≥ 0.8) 优先，然后 M_N 降序`。

已验证 M_N 的判别力很强 —— 真胞的 M_N 比库内错误候选高 **4–5 个数量级**
（如 mp-1029457：真胞 9.29e5 vs 库内最优 26.8）。所以**只要真胞进了库，
M_N 就能挑出来；挑不出来说明是生成端问题，不要去调排序权重。**

**产出**：`scripts/eval_prim_recovery_rank.py` + `results/prim_recovery_rank.json`
报 `lib / Top-20 / Top-1`（全部 powder_strict 口径）。

#### Gate 2
- **Top-1 ≥ 38%**（追平 McMaille 原生的 powder_strict Top-1）→ 通过
- Top-1 < 38% 但 lib 明显高于 Top-1 → 排序问题，报告 `首次命中排名` 分布
- lib 本身就低 → 回 Phase 1

---

### Phase 3 — 算力预算

Phase 1 探针中位耗时约 **39 s/样本**（还带了真值剪枝）。
正式流程只会更慢，需要压到可接受范围。

优先做这三件（按性价比排序，做完就停）：

1. **扩胞后去重**：同一基胞的不同 HNF 常给出同一格子，用 `cell_key` 去重
2. **快筛阈值**：`fom_stats` 是 ~3500 胞/s，`refine_cell` 是 ~680 胞/s，
   `symmetrize_and_refine` 只有 ~54 胞/s。把 spglib 那步严格限制在
   「已经 `coverage ≥ 0.5` 但没到 0.8」的候选上
3. **基胞数**：扫 `max_bases ∈ {50, 100, 200}`，看还原率的边际收益

**不要**为了提速去砍 `max_index`（真胞 index 分布一直拖到 8）。

## 5. 已知的坑（都是踩过的，别再踩）

1. **真值必须用原胞**。RealPXRD-solver 输出原胞，用 conventional 真值会把正确的
   原胞误判成 `|det|=2/4` 的亚胞。
2. **单独的 `find_mapping(ltol=0.05)` 不算命中**，必须叠加峰覆盖 ≥0.8。
   实测有大量几何过、峰对不上的假阳性。
3. **`cell_refine.hkl_grid` 的 `cap` 必须保持宽松（现为 60）**。之前写死 12，
   长轴/斜胞的反射被截断，`n_poss` 少算导致 M_N 虚高 10⁵ 倍，病态胞霸榜。
4. **波长必须 1.54184**（pymatgen XRDCalculator / MP100 模拟值），不是 1.5406。
5. **不要只按 coverage 排序** —— 超胞天然解释所有峰，必然霸榜。必须用 M_N
   （其 `N_poss` 项就是惩罚超胞的）。
6. **精修改不了 `|det|`，扩胞改不了精度**。两者必须串联，且顺序是
   **先精修基胞再扩胞**（这是本轮 26% → 50% 的全部来源）。
7. **精修只能救 ≲1% 的误差**（0.5%→精确，1%→cov 0.88，2%→失效）。
   所以基胞质量决定一切。
8. **Niggli 约化在 fcc 附近不稳定**，不能用它做对称性判断。用 spglib
   （`symmetrize_and_refine` 内部已处理，symprec 试 0.05/0.1/0.25）。
9. **`refine_cell` 的 `min_lines` 必须随自由度自适应**，写死 6 会让只有 5 条峰的
   样本直接跳过精修。
10. **正式流程严禁用真值体积剪枝**。探针里用过，那只是为了跑得快。
11. spglib 会往 stderr 刷 `No centring was found.`，跑全量前先抑制掉，否则日志没法看。

## 6. 天然上限（如实记录，不要试图刷过去）

峰数太少的样本，6 参数拟合本身欠定。例：**mp-1183073 只有 5 条峰**，
存在多个都能精确解释全部峰的胞（V=139.7 的四方胞与真菱方胞体积相同），
任何 FoM 都无法分辨。这类样本请在报告中单列，不要算作算法缺陷。
