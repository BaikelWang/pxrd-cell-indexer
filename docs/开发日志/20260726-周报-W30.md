1. **Peaks Transformer 完成优化收尾并进入放量阶段**：严格软损失和合成鲁棒课程均未在 MP100 上带来有效提升，训练侧继续调参正式收口。独立峰搜索在高对称 valid 上将 Top-20 从 53.8% 提升到 **64.4%**，接入 FOM 排序后，MP100 严格 elementwise 从单点 **23% 提升到约 36%**，oracle 晶系可到约 **42%**。同时完成 6M 数据放量：干净训练 MP100 为 29%，加噪训练达到 **35%**，比 100k 模型提升 **12pp**；valid1400 达到 **55.4%**。Peaks Transformer 主线已经从“继续换架构”转入“扩大数据 + 搜索补全”。

2. **McMaille 完成算法分析和并行优化**：打通“连续谱 → 寻峰 → 波长/零点 → 晶胞搜索 → 候选表”的完整路径，并确认单样本主要耗时来自单斜 Monte Carlo 搜索。直接开启 OpenMP 会因共享候选槽竞态出现 NaN、提前停止和错误 Top-1；修复竞态后，MP100 总耗时缩短约 **3.9 倍**，Top-1 mapping 从 52% 变为 50%，总体精度基本保持。当前主要遗留问题是单斜子集 Top-1 下降约 20pp，但 Top-20 不降，说明真解仍在候选池中，后续重点是稳定采样与排序。

3. **RealPXRD 实验完成，并成功接入 McMaille**：先验证了 RealPXRD 在“纯 XRD、无化学式”条件下的能力边界——最严格口径 Top-1 elementwise 约 **1%**，说明原 CSP 权重不能直接承担 indexing。随后将神经网络产生的晶胞种子接入 seeded McMaille，MP100 同口径下取得 **Top-20 mapping 约 97%、候选库 mapping 约 100%**，明显超过原生 McMaille 的 Top-20 mapping **53%**；Top-1 mapping 约 **51%**，已与原生 McMaille 52%、JADE9 57% 处于同一水平。也就是说，我们已经在“找到正确晶格族”的候选覆盖能力上超过 JADE9 和原生 McMaille。下一步不是继续扩大候选池，而是解决亚胞/超胞和精修问题，把候选覆盖优势转化为正确原胞 Top-1；当前亚胞还原第一轮达到约 **32%**。
