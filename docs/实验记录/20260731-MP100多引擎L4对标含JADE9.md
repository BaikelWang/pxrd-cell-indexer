# MP100 多引擎 L4-strict 对标（含 JADE9）

> 日期：2026-07-31  
> 协议：`results/mp100_benchmark/protocol.json`  
> 排行榜：`results/mp100_benchmark/l4_prim_leaderboard.json`

## 目标

在同一 MP100（n=100）、同一 **primitive L4-strict** 尺子上，对标公开/可用引擎，并纳入历史 JADE9 结果。

## 主表（primitive L4-strict）

| # | 系统 | Top-1 | Top-20 / lib | 备注 |
|---|---|---:|---:|---|
| 1 | **Ours（v4 wide K=100）** | **49.0%** | **59.0% / 59.0%** | seed→sym+LSQ→seeded Mc policy=1 |
| 2 | TREOR90 | 35.0% | 36.0% / 36.0% | 原生；同峰表 first-20 |
| 3 | **JADE9** | **30.0%** | =Top-1 | jade-index `.hkl` Top-1；仅 Top-1 |
| 4 | Native McMaille | 28.0% | 28.0% / 28.0% | `mp100_compare/original` |
| 5 | DICVOL91 | 19.0% | 19.0% / 19.0% | 原生 gfortran |
| 6 | ITO13 | 14.0% | 17.0% / 17.0% | 37/100 样本峰数 <20 |

主问题「我们是否 Top-1 最高」：**是**（49.0% ≫ 次席 TREOR 35.0%；相对 JADE9 +19 pp）。

### 对照：conventional 真值（非主表）

历史 JADE 常用 conventional 口径（`l4_prim_vs_conv.json`）：

| 引擎 | conv Top-1 strict | prim Top-1 strict |
|---|---:|---:|
| JADE9 | 46% | 30% |
| Native Mc | 38% | 28% |
| Ours v4（本轮） | 25% | **49%** |

Ours 输出更接近 primitive；主表统一用 prim，避免 JADE 的 conventional 优势被误读成 indexing 更强。

## 协议（写死）

- 数据：`data/MP-100samples-benchmark`，n=100
- 真值：CIF → SGA **primitive** 六参数
- 峰表（经典 / Mc / JADE 同源）：`mp100_seeded_phase5/<sid>/<stem>.dat`，按 2θ 取前 **20**；λ=**1.54184 Å**
- Ours：`pxrd_indexer_full6m_v4_wide_lr2e3/best.pt` → K=100 → symmetrize + LSQ → `mcmaille_seeded` policy=1、`MCM_NHKL_CAP=400`
- L4-strict：`find_mapping(ltol=0.05, atol=3°) ∧ |det−1|<0.25`
- 失败：timeout / 无解 / 解析失败 / 缺文件 → miss（分母仍 100）

## 结论

1. 在完整可跑表（含 JADE9）上，**Ours Top-1 仍最高**。
2. JADE9 在 **prim** 尺子上为 30%，低于 TREOR90（35%）；其历史 46% 来自 **conventional** 口径。
3. 原始种子库 recall（strict@100）71% → e2e Top-1 49% / lib 59%，排序与 Mc 闸门仍吃掉一部分库内命中。
