# Reranker V0：训练与冻结评测

> 2026-07-31 ｜ 对应设计：`docs/开发日志/20260731-Reranker设计与实验方案.md`

## 结论（先看这个）

**产品默认采用等权重线性式**，不采用在合成集上搜出的权重 / XGB：

```
score = 1.0·McM20_pct + 1.0·nn_dist_pct − 0.25·vol_dev
```

冻结评测（四池一次，无调参）：

| 集合 | McM20 Top-1 | V0 重排 | Δ | lib |
|---|---:|---:|---:|---:|
| CNRS K=1000 | 31.7% | **41.5%** | **+9.8** | 68.3% |
| CNRS K=100 | 39.0% | **43.1%** | **+4.1** | 64.2% |
| MP100 K=1000 | 50.0% | **57.0%** | **+7.0** | 69.0% |
| MP100 K=100 | 49.0% | **52.0%** | **+3.0** | 59.0% |

核心判据通过：`K=1000 + V0`（CNRS 41.5%）> `K=100 + McM20`（39.0%）。
四个池均无下降，`lib_strict` 不变。

模型文件：`results/rerank_v0/current/model.json`

## 数据与训练过程

### P1a：干净合成 × refine=lsq（失败路径）

- 目标 4000/1000 @ K=1000，LSQ refine 太慢（~5 样本/min，ETA 14h），中止于 363 条。
- 库形状过易：lib≈99%，headroom≈16%。
- 在该子集上选出的 XGB / 线性权重：**MP100 大涨、CNRS 几乎不动**（典型域差）。

### P1b：扰动合成 × refine=off（采用的训练集）

```bash
python3 scripts/build_rerank_dataset.py \
  --out data/rerank/v0_k1000_pert --n-train 1200 --n-dev 300 --k 1000 \
  --perturb --refine off --workers 32 --timeout 300
```

- 扰动：2θ 零点+抖动、弱峰丢弃、伪峰注入（McMaille 侧；NN seed 仍看干净峰）。
- 耗时：seed ~4 min + McMaille ~9 min + extract ~0.5 min。
- 库形状（更接近真实）：

| split | n | lib | top1_mcm20 | headroom |
|---|---:|---:|---:|---:|
| rr_train | 1175 | 89.6% | 63.1% | 26.5% |
| rr_dev | 290 | 88.3% | 66.9% | 21.4% |

### P2：V0 选择（仅在 rr_dev）

| 候选 | rr_dev Top-1 | 冻结 CNRS K1000 | 冻结 CNRS K100 |
|---|---:|---:|---:|
| McM20 基线 | 66.9% | 31.7% | 39.0% |
| 等权重 (1,1,0.25) | 75.5% | **41.5%** | **43.1%** |
| 合成优选线性 (0.25,0.75,0.5) | **80.3%** | 38.2% | 39.0% |
| XGBRanker | 80.3% | （未优于线性，未作为默认） | |

合成优选把权重偏向 `nn_dist`，对 MP100 更友好（+11 pp），但 CNRS K=100 零收益且 K=1000 弱于等权重。
按设计文档「MP100 涨而 CNRS 不涨 / 更弱 → 未通过」的精神，**默认锁定等权重**。

等权重本身未经评测集搜索（P0 的参考点），落在 P0 已验证稳健的权重邻域内；本次冻结是一次验证，不是调参。
