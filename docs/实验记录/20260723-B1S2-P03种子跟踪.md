## 2. 对 `search_empty_despite_ok_seed` 的单样深挖（mono 例）

样例 Niggli ≈ `(3.684, 5.010, 5.029, 103.88, 90, 90)`，真耦合为 **g23** → 需要 `monoclinic_a`。

| 检查 | 结果 |
|------|------|
| 真对角在 dedupe 后 opts | ✓ peaks `(5,2,1)` × miller `(2,2,2)` |
| 真 gvec exact | 15/15 ≥ min |
| a-unique + 真 g23 | params 还原正确 |
| b/c-unique（错轴） | exact 仅 5/15 |
| miller-first × dedupe80 后 true_rank | **83544（积的末尾）** |
| `monoclinic_a` 12s（生产 per-variant 份额） | **0 candidates** |
| 真 offdiag 在生产 `per_off` cap=12？ | **否**（(011) 基频占满；真值来自 (022)） |

结论：P0.2 的「kwargs 救不了」在机制上落实为两层 **枚举逻辑**：

1. **对角种子调度**：`(miller, peak)` 排序 + `diag_cap=80` 积 → 真种子（常需 \|h\|=2）排到 10⁴–10⁵ 量级，时间片内走不到。  
2. **offdiag 封顶**：即便走到真对角，`per_off_cap=12` 被低 Miller 区峰灌满，真 Gij 进不了列表。

P0.3 的「ok seed」指数学可还原，**不是**生产 capped 枚举路径可到达。

## 3. 其余 tag 一眼

- **diag_missing_in_opts**：`_axial_ok` 用全峰 + 1e-5，opts 用前 12 峰 + 1e-6 → 仍有「峰上有轴、窗/容差下无 opts」；mono 多为缺 G11。  
- **no_distinct_peak_triple**：三轴落到同一峰（或两峰）→ 积直接跳过。  
- **pool_miss**：种子级「够格」但池被别的高 match 胞占满 / 真胞未生成。
