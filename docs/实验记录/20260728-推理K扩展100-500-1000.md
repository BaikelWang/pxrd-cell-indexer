## 背景

K 只出现在推理和选模，**训练 loss 里没有 K**（rectified flow 每样本一个目标）。
所以扩 K 不改变模型，只改变采样预算。

当前链路固定为：

```
flow 种子 → 对称化吸附 → LSQ 精修 → 原生 McMaille 复刻(policy=1) → MCM_NHKL_CAP=400
```

## 种子池召回（未过 McMaille · prim · L4-strict）

| 100 | 67% | — |

```
@1=39%  @5=55%  @10=57%  @20=61%  @50=63%
@100=67%  @200=69%  @500=71%  @1000=73%
```

`mp-19337, mp-23225, mp-4807, mp-555805, mp-6738, mp-990238`。没有因采样噪声丢失的样本。

## 空库样本

**K=100 的 11 个**（`mp-12003, mp-1214853, mp-1214889, mp-13956, mp-18474, mp-559257,
mp-5625, mp-569787, mp-638061, mp-662553, mp-990238`）：全部种子被三重门拒绝，
日志均为 `gated out = 全部, deduped = 0`。其中 **10 个种子池里根本没有真原胞**，
只有 `mp-559257` 有（答案 Rp≈0.206）。同一批种子走非破坏多阶段时都有几百行库，
但其中 10 个仍无正确答案——**空库是原生「不达标即丢弃」的直接后果，
真正缺召回的根因是种子池没覆盖**。

**K=1000 只剩 2 个**：`mp-12003`、`mp-990238`（后者池里已有答案仍被清空）。

## 结论

- K=1000 主要抬 library / Top-5–20，**Top-1 只多 2 pp**。
- 耗时约 **×9**（3.3 s → 30.1 s）。
- 收益在变薄，说明瓶颈不是采样预算，是生成分布覆盖。
- 默认部署仍用 **K=100**；需要 library 时再上 1000。
