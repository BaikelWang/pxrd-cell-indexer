## 2. 流程与参数

```
pool → 全池 refine → 取 top 100 基胞
     → 峰导出体积先验 Vc=(1.25·d_max)³, 窗=[Vc/k, Vc·k], k=3
     → HNF 扩胞 (index≤8)，按 |V−Vc| 排序
     → refine → early-exit on 最终命中
```

| 参数 | 值 | 说明 |
|---|---|---|
| max_bases | 100 | |
| max_index | 8 | |
| vol_coeff | **1.25** | 计划写的 1.6 使 Vt/Vc 中位数=0.47；标定后 1.25 → 中位数≈1 |
| k | 3 | 覆盖约 **83%** 真胞体积（coeff=1.6/k=3 仅 61%） |
| max_refine | 12000 | 每样本精修上限（按 \|V−Vc\| 优先） |
| symmetrize | **关** | 10 样本探针上命中不依赖它；开启会把失败样本拖到数分钟 |

**严禁**：真值体积剪枝（本跑未使用）。

## 4. 失败归因（68 个未还原）

| 类别 | 数量 | 含义 |
|---|---:|---|
| 真胞体积在窗外 | 17 | 体积先验漏掉 |
| 真胞体积在窗内仍未中 | **51** | 主因：扩胞+精修没找到 powder_strict 解 |
| 其中撞上 refine 预算 | 57 | 搜了 12000 个仍无最终命中 |
| 峰数 <8 | 2 | 欠定风险（含文档点名的稀疏峰样本） |

**结论：体积先验不是主瓶颈（83% 真胞在窗内）。主瓶颈是「窗内也还原不出能 indexed 峰的正确原胞」。**

## 5. 对照历史实验

| 实验 | 口径 | 率 |
|---|---|---:|
| HNF 几何可恢复（旧） | 严格几何，无峰要求 | 100% |
| HNF 几何 + 峰覆盖（旧） | 严格 + cov≥0.8 | 18% |
| 扩胞→非线性精修（旧） | 严格 + cov≥0.8 | 26% |
| **本 Phase1：精修→扩胞→精修（盲）** | 严格 + cov≥0.8 | **32%** |
| 同协议 + 真值体积窗（10 样本探针） | 严格 + cov≥0.8 | 50% |
| 同协议 + 盲体积窗（10 样本探针） | 严格 + cov≥0.8 | 40% |

相对旧「扩完再精修」只涨了 26%→32%。几何 100% 与粉末 32% 之间仍有巨大鸿沟。

---

## 6. 根因（已用探针钉死）

1. **基胞精度不够**：精修只能稳住 ≲1% 误差；池内亚胞常带 2–5% 误差，×index 后峰对不上。
2. **假阳性胞霸占搜索**：许多扩胞后精修能达到 cov=1.0，但 `strict_match` 失败——能解释峰却不是真原胞。预算浪费在它们上面。
3. **盲体积窗仍偏宽**：为盖住 83% 真胞，每样本唯一扩胞数上万；即使用 \|V−Vc\| 排序，正确变换也常排在 12000 之外（或根本不存在足够准的基）。
4. **体积先验次要**：仅 17% 失败可直接归咎于窗外。

## 7. 建议的下一步（供决策，本轮不执行）

按方案 Gate：**<50% 已停下**。若继续，优先序建议：

1. **先抬基胞精度，再扩胞**：在扩之前对基胞做更强的对称约束精修 / 只用 `local_mc` 阶段高质量基，而不是全 `.allcells`。
2. **用峰一致性选「值得扩」的基**：只扩 `n_indexed` 高且 `mean_dq` 极小的基，而不是 top-100 by M_N。
3. **oracle 体积上界全量**：用真值体积窗跑满 100，确认天花板是 ~50% 还是能到 60%+；若天花板 <60%，Phase 2 排序无意义，必须改生成。
4. **不要**在当前 32% 库上调 FoM——方案已写明：真胞进库时 M_N 差 4–5 个数量级，问题在生成。
