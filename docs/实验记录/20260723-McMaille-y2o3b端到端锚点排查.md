## 4. 排查时怎么用这些锚点

1. **峰表对不对**：看 A01 后 `.imp` 里的 `2-THETA / d / I / W` 是否与 `.dat` 一致。  
2. **搜索有没有撞到真解**：看 console 立方段是否出现 `a≈10.6`；本次 **0.008 s 就撞到了**。  
3. **为什么还继续搜**：因为 `Rp=0.058 > Rmin=0.02`，黑盒不会在立方提前停。  
4. **为什么没跑单斜**：正交段 `Rp=0.018 < Rmin` → INTEREST 全局提前停（Occam 上仍由 McM20 把立方顶到第一）。  
5. **排序是否把真解顶到 Top-1**：看 A09 后 McM20 表第一行；本次是。  
6. **精修是否漂移**：对比 A09 的 `10.5983` 与 A10 CELREF 的 `10.6033`（正常小幅移动 + zero 校正）。
