## 下次重跑（必做）

### A. 对齐 RealPXRD：开在线 XRD 噪声

首轮：`train_augment: false`，`augment_shift_range: 0.0`（干净计算谱）。  
RealPXRD 训练集 `xrd_augment: True`，在 `__getitem__` 里对峰表做增强（**不写进 LMDB**）。

下次 6M 配置须改为：

| 项 | 首轮 | 下次（跟 RealPXRD） |
|----|------|---------------------|
| `data.train_augment` | false | **true** |
| `data.augment_shift_range` | 0.0 | **0.1** |
| intensity 噪声 | 关 | 默认 `noise_level=0.05`（`SpectrumAugmentConfig`） |
| intensity 缩放 | 关 | 默认 `(0.8, 1.2)` |
| valid_augment | false | 仍 false |

实现已 port：`src/.../data/dataset.py::augment_spectrum`（对标 `RealPXRD-Solver/app/data/dataset.py`）。

### B. 把算力吃满

首轮实测（4090D）：GPU util 长期约 **20%**、显存仅 **~2.5 / 24 GiB**、功耗 ~80 W → DataLoader/CPU 瓶颈。同机 McMaille 等会更糟。

| 旋钮 | 首轮 | 建议试 |
|------|------|--------|
| `data.batch_size` | 256 | **512 → 768**（OOM 再退） |
| `data.num_workers` | 8 | 按 CPU/内存扫 **8–16** |
| `data.prefetch_factor` | 默认 2 | **4–8** |
| `persistent_workers` | 默认 true | 保持 true |
| 并行杂活 | McMaille 等同机 | **尽量停掉或错峰** |

开训数分钟后用 `nvidia-smi` 验收：util/功耗上去、显存不再空闲。
